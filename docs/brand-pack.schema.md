# brand.json (Phase 1)

See `brands/guiji/brand.json` as the reference instance.

Required: `version`, `brandId`, `displayName`, `layout`, `theme`, `copy`, `queue`, `audio`, `assets`.
Optional reserved: `storeId`, `deviceId`.

`copy.standbyFallback`: `logo-on-primary` (not black banner).
`theme.bannerOpacity` default 0.85, min `bannerOpacityMin` 0.75.
